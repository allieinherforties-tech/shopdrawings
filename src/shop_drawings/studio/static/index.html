How it works

  1. Upload — drop in the design drawing for one piece.
  2. Extraction — the drawing is read into a typed spec: parts, dimensions, and assembly notes, each traced to the exact spot on the page it came from.
  3. Review — you answer the questions the reader couldn't resolve, confirm values against highlighted crops, and approve. Nothing proceeds on a guess.
  4. Outputs — once approved, the spec generates a 3D model, a DXF cut sheet, and a cut list.
